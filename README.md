A one-line entry for make.fun's "Worst Superpower" bounty: a program that invents the most useless superpower imaginable — the power to summon a single sock that is always the wrong one, always slightly damp, always from a stranger's dryer, and never its pair.

## Run it

```sh
python3 main.py
```

It writes the one-liner to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set) and prints it.
